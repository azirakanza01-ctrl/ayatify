# AyatIfy

AyatIfy is a static Quran-learning website with pages for personal learning, group learning, mentoring, articles, and site information.

## Run locally

Open `index.html` in a browser, or serve this folder with a local web server.

## GitHub Pages

Publish the `main` branch from the repository root. Keep `index.html` and the `assets` folder at the root level.
